# Citing GridHunt

If you use GridHunt in your research, please cite it. The repository's
[`CITATION.cff`](https://github.com/ajuanijustus/gridhunt/blob/main/CITATION.cff) holds the citation
details; GitHub's "Cite this repository" button turns it into BibTeX or APA.

```bibtex
@software{gridhunt,
  title  = {GridHunt: A Customizable Heterogeneous Predator-Prey Suite for Mixed-Motive MARL and Human-Agent Teaming},
  author = {Justus, Aju Ani and Baber, Chris and Acharya, Aditya and Stella, Leonardo},
  year   = {2026},
  url    = {https://github.com/ajuanijustus/gridhunt},
}
```
